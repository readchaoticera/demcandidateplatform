# GitHub Pages site

Two static pages built from a completed collection run:

| File | What it is |
|---|---|
| `index.html` | The Explorer: searchable, filterable table of all 432 candidates |
| `analysis.html` | The written analysis: headline findings, method, limits |
| `house.css` | Shared Explorer house style — tokens and primitives |
| `data.json` | The Explorer's payload, regenerated by `scripts/build_site.py` |

## House style

`house.css` carries the same design system as the FBIC and ArabiCCR Explorers:
identical tokens (`--paper`, `--ink`, `--chrome`, `--s1`–`--s6`), the same
Iowan Old Style / system-sans / system-mono stacks, the same 2px masthead rule,
10px panels and 999px chips. Keep the token block byte-identical across
projects so the family reads as one system; project-specific rules belong in
the page, not in `house.css`.

There are no web fonts by design — every face is a system stack, so a page
renders identically offline or behind a restrictive proxy.

The Artifact copy of the analysis is generated by `scripts/build_artifact.py`,
which inlines `house.css` and strips the document skeleton, because an Artifact
is published as a single file behind a strict CSP.

## Enabling Pages

Repository **Settings → Pages → Build and deployment**:

- **Source:** Deploy from a branch
- **Branch:** `claude/house-candidates-medicare-analysis-qyihx3` (this repo's default branch) · folder `/docs`

The site then publishes at `https://readchaoticera.github.io/demcandidateplatform/`.

`.nojekyll` is present so Pages serves the files as-is rather than running them
through Jekyll.

## Rebuilding after a new run

```bash
dcp run --as-of $(date +%Y-%m-%d)
python scripts/build_site.py
```

`build_site.py` reads `data/out/roster.json` and `data/out/analysis.json` and
rewrites `docs/data.json`. The dashboard picks up the new numbers on reload —
the stat tiles, filter counts and footer all derive from the payload, so
nothing in `index.html` needs editing.

## Working on it locally

The page fetches `data.json` over HTTP, so it must be served rather than opened
from disk:

```bash
python3 -m http.server -d docs 8000
```
